📱 iOS 설치 가이드

Butterfly Tester PWA를 홈 화면에 추가하는 방법

⚠️ iOS에서 푸시 알림을 받으려면 아래 단계를 완료해야 합니다.
Android Chrome은 URL 접속만으로 바로 사용 가능합니다.
1

Safari로 열기

Chrome이 아닌 Safari로 앱 URL을 열어주세요. iOS 16.4 미만은 Web Push 미지원.

2

공유 버튼 탭

하단 Safari 툴바의 공유(□↑) 버튼을 탭합니다.

3

홈 화면에 추가

스크롤하여 "홈 화면에 추가"를 탭합니다.

4

홈 화면 아이콘으로 실행

Safari 탭이 아닌 홈 화면의 아이콘을 탭하여 실행합니다.

5

알림 권한 허용

알림 권한 요청이 표시되면 "허용"을 탭합니다.

✅ 설정 완료! 이제 앱이 닫혀 있어도 푸시 알림을 받을 수 있습니다.
